# VideoToGifConverter

A desktop application for converting videos into optimized GIFs using FFmpeg.

## Features

- Convert videos to GIFs
- Adjustable output quality
- Adjustable frame rate
- Adjustable resolution
- Preview before conversion
- UI-independent conversion logic

## Project Structure

### VideoToGifConverter.Core

- Business logic
- Conversion services
- Shared models

### VideoToGifConverter.Desktop

- WPF desktop application
- User interface

### VideoToGifConverter.Tests

- Unit tests

## Technologies

- C#
- .NET 10
- WPF
- FFmpeg
